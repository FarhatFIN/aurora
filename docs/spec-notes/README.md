# Spec-reading notes (§2.2)

One file per standard topic the project has read in force: a 5–15 line
summary of what was read, so the next session does not re-read 400 lines to
relearn it. Named `docs/spec-notes/<topic>.md` (e.g., `css-text-decoration.md`,
`html-in-body-insertion.md`).

The first notes appear with M1 (URL/HTTP) and M2 (HTML tokenization).
