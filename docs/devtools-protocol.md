# DevTools Protocol

The local debugging protocol for the Console, Inspector, Network, and
Performance panels (§5.19.5). Every protocol message change updates this file
(§11.2).

## Status at M0

Not designed yet — the Console and Inspector land with M11, the Network panel
with M12, the Performance panel with M13 (§7.13–§7.15). The protocol's
message table appears here from M11 onward.
